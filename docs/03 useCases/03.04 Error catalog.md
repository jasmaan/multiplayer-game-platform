# PlatformError Catalog

All platform-level errors are expressed via `ca.ucalgary.seng300.core.PlatformError`.

## Room Errors

**ROOM_FULL** (WARN)
- Thrown by: `Room.addPlayer()`, `RoomManager.joinRoom()`
- When player tries to join a room where `players.size() >= maxPlayers`

**ROOM_NOT_FOUND** (ERROR)
- Thrown by: `RoomManager.joinRoom()`, `RoomManager.leaveRoom()`
- `rooms.get(roomId)` returns null — room was closed or roomId is invalid

**PLAYER_ALREADY_IN_ROOM** (WARN)
- Thrown by: `Room.addPlayer()`, `RoomManager.joinRoom()`
- Duplicate join request — player is already a member of this room

**PLAYER_NOT_IN_ROOM** (ERROR)
- Thrown by: `Room.removePlayer()`, `RoomManager.leaveRoom()`
- `players.remove(playerId)` returns false — player is not in this room

## Session Errors

**INVALID_SESSION** (ERROR)
- Thrown by: `GameSessionManager`
- Session ID not found in active sessions map

**SESSION_NOT_FOUND** (ERROR)
- Thrown by: `GameSessionManager`
- Alias for session lookup failure in specific pipeline steps

**NOT_YOUR_TURN** (WARN)
- Thrown by: `GameSessionManager.submitMove()`
- Submitting player is not the current `activePlayerId`

**INVALID_MOVE** (WARN)
- Thrown by: `GameSessionManager.submitMove()` after `GameEngine.validateMove()` returns failure
- Move failed engine-level validation

**GAME_ALREADY_OVER** (ERROR)
- Thrown by: `GameSessionManager.submitMove()`
- Move submitted to a session with status `GAME_OVER`

**INVALID_STATE** (ERROR)
- Thrown by: `GameSessionManager` internal state checks
- Session is in an unexpected or inconsistent state

**ENGINE_NOT_REGISTERED** (ERROR)
- Thrown by: `GameSessionManager.startSession()`
- No `GameEngine` registered for the requested `gameType`

## Auth / Player Errors

**AUTH_FAILED** (ERROR)
- Thrown by: `PlatformCore.login()`
- Credential mismatch or player not found in credentials store

**UNKNOWN_PLAYER** (ERROR)
- Thrown by: various platform operations
- Player ID not recognized in any active context

## Matchmaking Errors

**QUEUE_FAILED** (WARN)
- Thrown by: `MatchMaking.addPlayerToQueue()`
- Player could not be added to queue (already queued or other constraint)
