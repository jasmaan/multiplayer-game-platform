# S1.4 - GameState Data Model
## Owner: Platform Core Sub-team
## Sub-Team: Platform Core
## Iteration: 1


## Purpose

"GameState" reflects the current state of a session. It stores information that includes:
- Whose turn it is
- Whether the move is valid
- Advancement of the game
- Whether the game is done

## Data Fields

- board: Object
- playerOrder: List<String>
- currentTurnIndex: int
- activePlayerId: String
- moveHistory: List<Object>
- status: GameStatus
- sessionId: String
- gameType: String

## Rules

The following must always hold:

- The number of players must be greater than or equal to 2
- The currentTurnIndex must be greater than or equal zero and less than the number of players
- The activePlayerId must be equal to the player whose turn it is
- If the status of the game is "GAME_OVER", then no more moves can be made

## Turn rotation

To accommodate N-players in a single session, the following formula will cycle through the players given the number of turns that have passed.

currentTurnIndex = (currentTurnIndex + 1) % playerOrder.size()

This will ensure that the above rule regarding the currentTurnIndex is upheld. 

## Move Handling
- If a move was rejected, the state of the game must not be changed
- Moves that are accepted will:
  - update "board"
  - append to the "moveHistory"
  - if the game is not over, advance the turn
- If the game has reached an end
  - the status of the game will be "GAME_OVER"
