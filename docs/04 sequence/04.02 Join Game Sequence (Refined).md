# Join Matchmaking and Start a Session (Refined for Iteration 1)

## About

Refined sequence showing the full flow from queueing through matchmaking, room creation, session initialization, and game start. Includes party queueing and queue-leave scenarios.

## Owner: Platform Core Sub-team

## PlantUML Editor Code

```uml
@startuml
title Sequence - Queue -> Match Found -> Join Game (Refined)

actor Player as P1
actor "Matched Player" as P2
participant "GUI\n(Dashboard)" as GUI
participant "PlatformCore" as Core
participant "MatchMaking" as MM
participant "PlayerQueue" as Queue
participant "RoomManager" as RM
participant "GameSessionManager" as GSM
participant "GameEngine" as Engine
participant "EventBus" as Bus

== Enqueue ==

P1 -> GUI : choose gameType\nclick "Find Match"
GUI -> Core : joinQueue(playerId, gameType)
Core -> MM : addPlayerToQueue(playerId, gameType)
MM -> Queue : enqueue(playerId)
Queue --> MM : position in queue
MM --> Core : queued(position)
Core --> GUI : showQueueStatus(position)

== Matchmaking (runs periodically or on new player) ==

... time passes / another player joins queue ...

MM -> Queue : peek() (check available players)
MM -> MM : matchPlayers(gameType)\nevaluate skill/rank proximity
MM --> MM : matchFound([P1, P2])

== Match Found ==

MM -> Bus : publish(MatchFoundEvent(players, gameType))
Bus --> Core : deliver(MatchFoundEvent)

Core -> Core : notifyMatchedPlayers()
Core --> GUI : showMatchFoundAlert("Match found!")

== Room & Session Creation ==

Core -> RM : createRoom(P1, gameType, 2)
RM --> Core : Room(roomId, OPEN)
Core -> RM : joinRoom(roomId, P1)
Core -> RM : joinRoom(roomId, P2)
RM --> Core : room FULL

Core -> GSM : startSession(roomId, gameType, [P1, P2])
GSM -> Engine : createInitialState([P1, P2])
Engine --> GSM : initialState (board, first player)
GSM -> GSM : create GameSession\nset status = IN_PROGRESS

GSM -> Bus : publish(GameStateUpdate(\nstatus=STARTING,\nactivePlayerId=P1))
Bus --> Core : deliver(GameStateUpdate)

== Players Enter Game ==

Core --> GUI : openGameView(sessionId)
GUI -> GUI : render game board\nshow initial state

alt Player tries to leave queue before match
  P1 -> GUI : click "Leave Queue"
  GUI -> Core : leaveQueue(playerId)
  Core -> MM : removePlayer(playerId)
  MM -> Queue : remove(playerId)
  Core --> GUI : returnToDashboard()
end

@enduml
```
