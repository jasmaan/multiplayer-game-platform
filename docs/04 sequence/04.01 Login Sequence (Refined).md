# Login and Reach Dashboard (Refined for Iteration 1)

## About

Refined login sequence showing the full flow from credential entry through authentication to dashboard display, including session establishment, error handling, and registration fallback.

## Owner: Platform Core Sub-team

## PlantUML Editor Code

```uml
@startuml
title Sequence - Login -> Game Dashboard (Refined)

actor Player
participant "GUI\n(LoginPage)" as GUI
participant "PlatformCore" as Core
participant "CredentialsDatabase\n(stub)" as Store
participant "GUI\n(Dashboard)" as Dashboard

== Login Flow ==

Player -> GUI : enter username/password\nclick "Login"
GUI -> Core : login(username, password)
Core -> Store : findPlayerByUsername(username)

alt player not found
  Store --> Core : null
  Core --> GUI : loginFailed("Account not found")
  GUI -> GUI : display error message
  GUI -> Player : prompt to register or retry
else player found
  Store --> Core : Player object
  Core -> Core : verify password match

  alt password incorrect
    Core --> GUI : loginFailed("Invalid password")
    GUI -> GUI : display error message
  else password correct
    Core -> Core : createSession(playerId)\nset currentUser
    Core --> GUI : loginSuccess(playerId, sessionToken)

    == Navigate to Dashboard ==

    GUI -> Dashboard : initialize
    Dashboard -> Core : getPlayerStats(playerId)
    Core --> Dashboard : stats data
    Dashboard -> Core : getActiveSessionsForPlayer(playerId)
    Core --> Dashboard : active sessions (if any)
    Dashboard -> Dashboard : render dashboard\n(game list, profile summary,\nactive game alerts)
    Dashboard -> Player : display Dashboard
  end
end

== Registration Fallback ==

alt player chooses to register
  Player -> GUI : click "Create Account"
  GUI -> GUI : display registration form
  Player -> GUI : enter username, email, password
  GUI -> Core : register(username, email, password)
  Core -> Store : usernameLookup(username)
  Store --> Core : exists / not exists

  alt username taken
    Core --> GUI : registrationFailed("Username taken")
    GUI -> GUI : display error
  else username available
    Core -> Store : addNewPlayer(username, email,\npassword, BRONZE)
    Store --> Core : success
    Core -> Core : createSession(playerId)
    Core --> GUI : registrationSuccess + loginSuccess
    GUI -> Dashboard : initialize
  end
end

@enduml
```
