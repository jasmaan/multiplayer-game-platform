# 04 - UI & Navigation #

## About this Diagram ##

This diagram represents the user interface and navigation flow for the JavaFX-based multiplayer board game platform. It shows the 12 FXML-backed screens, their controllers, key public methods, and how users navigate between them. The UI layer is reactive: it displays information and sends user actions to `PlatformCore`, but it does not own game logic or session state. All state updates originate from `PlatformCore` (via `NotificationService` or `EventBus`) or from the server (via `NetworkClient`/`ClientEventDispatcher` WebSocket events). The platform supports a **dual mode**: local (in-memory, `EventBus`) and network (WebSocket, `NetworkClient`).

## Backend API Calls ##

The UI never talks to game engines directly. All calls go through `PlatformCore` (local mode) or `NetworkClient` (network mode).

| Controller | PlatformCore calls | NetworkClient calls |
|---|---|---|
| `LoginPageController` | `login()` | `login()` |
| `RegistrationPageController` | `registerPlayer()` | `register()` |
| `DashboardPageController` | `getLeaderboard()`, `getNotificationService()` | — |
| `GameRoomPageController` | `getRoomManager()`, `joinQueue()` | `send(ROOM_CREATE/JOIN)` |
| `QueuePageController` | `leaveQueue()` | — |
| `TicTacToeGamePageController` | `submitMove()`, `setChatMessageCallback()` | `enableNetworkMode()` |
| `ConnectFourGamePageController` | `submitMove()`, `setChatMessageCallback()` | `enableNetworkMode()` |
| `CheckersGamePageController` | `submitMove()`, `setChatMessageCallback()` | `enableNetworkMode()` |

`PlatformCore` pushes back to the UI via `NotificationService` (implemented by `DashboardPageController`, `GameRoomPageController`, and `QueuePageController`).

## Dual-Mode Architecture ##

| Aspect | Local Mode | Network Mode |
|--------|-----------|-------------|
| State source | `PlatformCore` in-memory | Server via WebSocket |
| Events | `EventBus` pub/sub | `ClientEventDispatcher` (JSON frames) |
| Match found | `NotificationService` callback | `MATCH_FOUND` WS event |
| Move submission | `PlatformCore.submitMove()` | `NetworkClient.send(GAME_MOVE, …)` |
| Game state sync | `EventBus.GameStateUpdate` | `GAME_STATE` WS frame |
| Activation | default | `controller.enableNetworkMode(playerId, client)` |
