# S1.1 - GameSessionManager Design Specification
## Owner: Platform Core Sub-team
## Sub-Team: Platform Core
## Iteration: 1

---

 # Purpose

"GameSessionManager" is responsible for managing the lifecycles of active game sessions on the platform.

It serves to:
- Create sessions from rooms
- Run the move processing pipeline
- Delegate rule validation to game-specific engines
- Track active sessions
- Cleanly end sessions

---

# Design
- Support for multiple game types
- Keep rule logic separate from game logic
- Keep GameSessionManager testable
- Support N-player turn rotation


---

# Core Responsibilities

## Session Lifecycle
- Create a session when a room starts
- Store and retrieve active sessions
- End and clean up sessions


## Move Processing Pipeline

For each move:
- Verify session exists
- Verify it is the player's turn
- Validate move through the GameEngine
- Apply move through the GameEngine
- Evaluate end condition (win, lose, tie)
- Advance turn if the game is still going
- Produce the right GameEvent

## Engine Registry

Maintain a registry mapping:

    gameType (String) -> GameEngine Implementation

This will allow for different types of games without modifying the core session logic.
